# HOTHOUSE

一本道の選択型ADV（プレイ時間 30分〜2時間）のモック。

## 動かし方

`index.html` をブラウザで開く。ビルド不要。

- 画面：16:9（1920×1080 をウィンドウに合わせて縮小）
- ADV：字幕は画面下部に表示。右上の星から操作メニューを開ける。選択肢のインクは WebGL で描画
- 素材：`assets/`（背景・立ち絵・スチル・エフェクト）。読み込めない素材はシェーダーの仮描画に切り替わる。音なし
- アートの仕様：`docs/HOTHOUSE_art_brief.md`

## 収録範囲

シナリオ全編（プロローグ〜最終章、結末 E1 温室／E2 海峡／E3 流れ星の夜）と、追加章（仮の骨組み）。

結末と分岐の仕様は `docs/plot.md` の「結末と分岐」を参照。

## シナリオの書き方

`index.html` 内の `PROLOGUE` に原稿をそのまま書く（Google ドキュメント「HOTHOUSE」の本文と同じ）。追加章は `EXTRA` に入っている。`fromScript()` が Aube と同じ order 形式に変換する。

| 書き方 | 意味 |
|---|---|
| `名前：本文` | セリフ（Talk） |
| `：` のない行 | 地の文（Descriptive） |
| `表示名＝話者：本文` | 名前を伏せたセリフ |
| `＞ラベル` | 選択肢（連続行で複数） |
| `｜本文` | 直前の `＞` を選んだときだけ流れる行。分岐が終わると次の行に合流 |
| `＞「台詞」` | ラベルを「」で囲むと、選んだあと主人公の台詞として表示 |
| `「本文」` | 主人公のセリフ。選択肢1つの選択として出し、選ぶとセリフとして表示（`ジョナス：本文` も同じ扱い）。主人公のセリフはすべてプレイヤーが選んで言う |
| `（暗転）` | 暗転。その他の（　）はメモとして無視 |
| `{player}` | 主人公の名前 |

演出行（`@`）：

| 行 | 内容 |
|---|---|
| `@bg 背景` | 背景変更（slope / observatory / lab / church） |
| `@in 名前 位置 秒 表情` | 登場（Left / Center / Right）。表情は省略可（例：テオの `Live`＝生前） |
| `@out 名前 秒` / `@clear 秒` | 退場 / 全員退場 |
| `@fadein 秒` / `@fadeout 秒` | フェード |
| `@meteor 秒` / `@flash 秒` / `@shake` | 演出 |
| `@wait 秒` | 字幕と操作表示を消して待機 |
| `@phase 大\|小` | 左上に章題を一時表示 |
| `@cmd 命令` | ゲーム側への命令（例：`@cmd param love_j 10; param mourn 6`） |
| `@monologue 本文` | 独白を画面中央に表示 |
| `@cg 名前 秒` / `@cg off 秒` | スチル表示 / 消去 |
| `@shower 強さ 秒` | 流星群テクスチャ（0で消える） |
| `@sparkle 強さ 秒` | 星のきらめきテクスチャ |
| `@head 場面\|題\|説明` | 次の選択肢の見出し |

行頭に `+` を付けると直前の行と同時に実行（Join）。

## 構成

ADV 部は Aube のコマンドパターンを踏襲。

- order：`order_id / order_type / sequence / speaker_id / dialog_text / override_display_name / file_path / position / facial_expression / override_text_speed / duration`
- `OrderHandler(type, fn)` で種類ごとにハンドラを登録
- `StoryPlayer`：Append で群を区切り、Join は同時実行

## 操作

HUD は普段は出さない。右下の隅にはいつも小さな星が瞬いていて、マウスを寄せる（スマホはタップする）と星が集まって LOG / AUTO / SKIP / MENU の文字になる。カーソルが離れた瞬間に文字はほどけて夜空に還る（タップで開いたときは3.5秒で閉じる）。

| 操作 | 内容 |
|---|---|
| クリック / Enter / Space / ↓ / ホイール下 | 読み進め（AUTO・SKIP 中にクリックすると止まる） |
| ホイール上 / ↑ / L | ログ（ログの一番下でホイール下 → 閉じる） |
| 右クリック / H / スマホは長押し | 文字を隠して絵だけを見る（もう一度クリックで戻す） |
| Ctrl（押している間） | スキップ |
| A | オート |
| Esc | メニュー |

AUTO・SKIP 中は右下の同じ場所に小さく表示が出る。

## デバッグ

Aube の AubeDebugWindow と同じ作り（登録簿と画面を分ける／行の種類は Button・Toggle・Int・String・InputAction・View／値は getter・setter で持つ）。

- 開き方：**Tab** キー、画面左上の長押し（0.8秒）、3本指の長押し。Esc で閉じる
- URL に `?debug=0` を付けると無効になる
- **シーン**：`@phase` を書いた場所が自動で飛び先になる。「ここから」で、その場面から再生する（背景は飛び先の `@bg` を当てる）。order_id を直接指定して再生もできる
- **システム**：AUTO / SKIP / 文字を隠す / 主人公の名前 / 画面のデバッグボタン / タイトルへ戻る
- **分岐**：隠し変数の確認と書き換え、追加章の条件をまとめて満たす、棚の記録の付け外し
- **情報**：現在の場面、order_id、背景、登場中のキャラ、ログ全文
- コマンドを足すときは `DebugService.button / toggle / int / string / inputAction / view` で登録する
- コンソールからは `HH`（`HH.playFrom(order_id)` など）で触れる

## 原稿の追加の書き方

| 行 | 内容 |
|---|---|
| `@end` | そこで結末。分岐（`｜`）の中に置くとバッドエンドになる |
| `@add 名前` / `@add 名前 数` | 隠し変数を増やす（画面には出さない）。選択肢の分岐の中に `｜@add filou` のように書く |
| `@set 名前 値` | 隠し変数に値を入れる |
| `@if 条件` 〜 `@elif 条件` 〜 `@else` 〜 `@endif` | 条件で流れを分ける。入れ子にできる |
| `＞［条件］ラベル` | 条件を満たすときだけ出る選択肢。ひとつも出なければ、その選択ごと飛ばす |
| `@label 名前` / `@goto 名前` | 飛び先の目印と、そこへの移動（PROLOGUE と EXTRA をまたいでよい） |
| `@item 名前` | 周回をまたいで残る記録（タイトルの棚に飾る物）。入手した／していないの2状態だけ |

条件の書き方：`filou>=4`、`liv>=3 || leif>=3`、`c_liv && c_leif`、`!c_theo`、`item:liv`（棚の記録）。比較は `>= <= == != > <`、`&&` が `||` より先。

使っている隠し変数：`filou`（フィルウを見ていた）、`liv` / `leif` / `karil`（想いの条件）、`c_liv` など（追加章で呼んだ人）。棚の記録：`bud` / `liv` / `leif` / `filou` / `karil` / `theo`（`localStorage` の `hothouse.items`）。
| `先生：本文` など | NAME2ID にない話者は、書いた名前をそのまま名前欄に出す |
