# HOTHOUSE アートブリーフ（画像生成用）

一本道の選択型ADV『HOTHOUSE』の立ち絵・表情差分・背景・スチルを生成するための資料。
この資料の内容を最優先し、書かれていないことは「金・銀・黒、死者の静けさ、ガラスの温室」の方向で補うこと。

---

## 0. 作品の空気

- 流星群の夜、11歳の少年ジョナスは展望台から落ちて死ぬ。目を覚ますと、時間の外にある「研究室」にいた
- 研究室には、生き返りを研究する死者たちがいる。彼らは生きている少女ルネの悲しみで「蘇りの異能」を咲かせようとしている
- 研究室は**黒いガラスの温室**。細い金の骨組み、天井の向こうに**星がひとつだけ閉じ込められている**
- キーワード：死者の静けさ／ガラスの覆い／星／温室で無理に咲かされる花／美しいけれど取り返しのつかないもの
- 舞台はフランス南部の小さな街（ピレネー近く）。時代は現代〜近未来、華美なSF要素は控えめ
- 季節は**冬**。流星群の夜も冬。生者の服は冬服にする

## 1. 全体の画風

- **日本のノベルゲーム向けの、繊細なアニメ調**。細く柔らかい線、色数は少なめ、半厚塗り
- 光は**逆光とリムライト**が基本。黒い背景の上で輪郭が金や銀に光る
- 死者（研究室の5人＋テオ）：肌はやや青白く、影は冷たい色。目のハイライトは控えめ
- 生者（ルネ、生前の回想）：肌に血色があり、光は暖かい
- 実在の作家・作品の模倣はしない。文字・ロゴ・署名は画像に入れない
- 子どもキャラ（11歳）は年相応の体型と服装にする。性的な要素は一切入れない
- 傷は「痕」として控えめに描く。流血やグロテスクな表現はしない

## 2. 共通ルール：死因につながるデザイン

研究室の死者は全員、**死んだときの痕を身につけている**。プレイヤーが「なぜ室内なのにマフラー？」「なぜ靴が片方ない？」と思えるように、さりげなく入れる。

### 背の順

カリル 178cm ＞ フィルウ 176cm ＞ レイフ 168cm ＞ リヴ 162cm ＞ テオ 約140cm ＞ ルネ 約137cm（ジョナスも約140cm。視点の高さの基準）

立ち絵（ジョナス以外）は全員を同じ縮尺で描き、並べたときにこの差が出るようにする。

## 3. キャラクター

### カリル・ラセール（40）研究室の主／死者

- フランス人の天文学者。研究室では穏やかで、優しく、生き生きしている。ただし笑顔の奥は空っぽ
- 外見：若い頃からずっと「童顔」と言われてきた。40歳だが30歳前後に見える
  - 顔：丸みのある輪郭、なめらかな頬、大きめで少し垂れた金色の瞳、長いまつげ、細くやさしい眉。シャープな大人の顔にはしない
  - そのうえで薄い隈、乾いた唇、やつれを少しだけ足し、「童顔のまま老けた」印象にする
  - 髪：柔らかい猫っ毛の、ゆるいウェーブがある淡いブロンド。広がりは抑え、落ち着いてまとまった少し重さのある長髪。背中の中ほどまである後ろ髪を**黒いリボン**で低い位置にひとつ結び、**本人の右肩（画面左）**から胸の前へ垂らす
  - 姿勢：顎を少し引いたうつむき加減。疲れて見える
- 服：廃人同然の6年間、フィルウが着替えを手伝いやすかった服。前開きの白いボタンシャツ（第一ボタンが外れ、少し着崩れ）、黒いスラックス、その上に丈の長い薄手の**ロングカーディガン**（チャコールグレー、ゆったりした羽織もの）。白衣は着ない
- 左手の薬指に**結婚指輪**（離婚しているのに外していない）
- 死因の痕：炎の中で崩落の下敷きになって死んだ
  - ロングカーディガンの片側の裾と背中が**焦げて煤けている**。シャツの袖口にも少し煤
  - 片手の甲から手首に、古い**火傷の痕**

### フィルウ・ブランシャール（17）助手／死者

- 別作品（暁星）のフィルウとは別の世界線の同一人物
- **明らかな悪者には見せない**。穏やかでやさしい、人懐っこく感じのいい微笑み（目は細めすぎず瞳が見える）。胡散くささは「感じがよすぎる」程度のほんのり。不気味さやニヤリとした印象は出さず、豹変は表情差分で見せる
- 姿勢はまっすぐ（猫背にしない）
- 背景：働かないカリルの代わりに生活費を稼ぐため、裏社会（ギャング）の仕事にも少し染まっている。その結果、ある程度身なりを整えた、少し大人びた見た目
- 髪：**白に近い銀髪**、毛先にかけて青紫のグラデーション。無造作すぎず、ある程度セットされた短髪。前髪が目にかかる。瞳は青紫
- **右目（本人の右＝画面左）を縦にまたぐ縫合の跡**。傷は上下で別々の2本：眉の下からまぶたの上まで、下まぶたの下から頬まで。目そのものは無事。カリルが死んだ火事で瓦礫が刺さった傷
- 装飾は多いが品よくまとめる：両耳に複数のピアス、細めのネックレスの重ね付け（ドッグタグ風など。十字架はなし）、指輪複数、シンプルな腕時計
- 服：**白のテーラードジャケット**（前を開けて着る）と**白のスラックス**、インナーだけ**黒のハイネック**。黒の革靴。少し浮いた、意味不明なスーツの組み合わせが彼らしい
- 喧嘩で一度も勝てないが、見た目に傷は出さない（絆創膏・切り傷なし。拳の擦り傷がごく薄くある程度）
- 死因の痕：研究所に火をつけた
  - **指先が煤で黒い**。白いジャケットの袖口に煤の汚れ
- 注意：本人の最期（自死）を連想させる描写は入れない

### テオ・ラセール（11）カリルの息子／死者

- 「やさしい王子さま」。ルネに手を差し出す子。研究室ではずっと伏し目で、ジョナスと目を合わせない
- 体型：年相応の11歳。華奢で線の細い、うすほそ
- 顔：童顔のカリルの面影（垂れ気味のやさしい目元）。瞳は淡い金
- 髪：**淡い金髪のやわらかい癖っ毛、センターパート**。ふわっとした巻き毛だが、清潔感があって品がいい
- 服：クリーム色の大きめの**ケーブル編みカーディガン**、白い襟付きシャツ、くすんだ茶色の半ズボン、白いハイソックス
- **真鍮の小さな望遠鏡**を首から下げている（父から借りたもの）
- 死因の痕：展望台の床が抜けて落ちた
  - **片方の靴がない**。片足は茶色の編み上げブーツ、もう片足は白いソックスだけ（裏が汚れている）
  - 両膝に擦り傷。カーディガンの裾がほつれている
- 差分：生前の回想版（血色あり、明るい笑顔）

### ジョナス（11）主人公／死者

- プレイヤーの**一人称視点**のキャラクター。**立ち絵もスチルも作らず、姿は一切描かない**
- スチルはすべてジョナスの視点から見た構図にする。必要なら手や手首だけが画面に入るのはよい
- 設定上の見た目（描かないが、手元が映るときの参考）：黒髪、日に焼けた細い手。片方の手首に、テオにつかまれた指の跡

### 双子共通（リヴ・レイフ）

- **王道のヨーロッパ系ローファンタジー世界の美人双子**。ノルウェー系の、整った美しい顔立ちのよく似た二人
- プラチナに近い銀髪、灰青の瞳、白い肌。気品があり、静かで少し寂しげ
- 服：北欧の民族衣装の要素を取り入れた、ローファンタジーの旅装・騎士見習い風。黒〜濃紺のウールに銀糸の刺繍（北欧風の植物文様）、革のベルトや留め具。二人で対になるデザイン
- 注意：作中設定では深層東京（近未来の東京）の訓練校の生徒。見た目はこの方向で作り、設定側との整合は別途決める

### 双子共通

- **王道の美人双子**。顔立ち・銀髪・淡い灰青の瞳をそろえる
- 二人とも**深みと闇のある癒し系**：やわらかく穏やかで、そばにいると安心する。でも瞳の奥に喪失と影がある。冷たさや威圧感は出さない
- 深層東京（近未来の東京）の訓練校の黒い制服：詰襟風のシャツジャケット、ベルト、ゆったりした黒いパンツ、編み上げブーツ。片腕に灰色の腕章
- ノルウェー系移住者の子。互いに「別の世界線の片割れ」

### リヴ・スン（15）死者／主人公の味方

- 髪：淡い金がかった銀髪、肩下まで。片側に細い三つ編みを一本垂らす
- **琥珀色のニットのマフラー**を室内でも巻いて、首元を隠している
- 死因の痕：危険な任務に自分から出て死んだ。マフラーの下に何があるかは描かない
- 存在が削れている：**指先が透けて、星屑のように欠けている**
- 表情：やさしく包み込むような、少しさびしげな微笑み。両手を体の前で軽く重ねる

### レイフ・スン（16）死者／妨害者

- 髪：リヴと同じ銀髪。襟足まで届く長さで、うなじで小さくひとつに結ぶ
- 差し色は氷のような青（腕章の縁や小物に少し）
- 死因の痕：成人して親の債務を継ぎ、制度の任務の中で死んだ
  - 手首に**識別番号の入ったバンド**
  - 頬に一筋のごく薄い傷
- 表情：伏し目がちな、静かでやさしい微笑み。奥にひとりで取り残された孤独。片手はポケット

### ルネ・フルーリー（11）キーマン／生者

- 「お姫さま」。わがままで、守られるのが当然と思っている。でもちゃんとかわいい。ジョナスのことが好き
- 外見：ローズ系の淡いストロベリーブロンド、ゆるいウェーブのロングヘア。ハーフアップを小さなシンプルなローズ色のヘアクリップで留める（リボンはなし）。大きなローズがかった茶色の瞳
- 服（流星群の夜・冬）：ゴシックやクラシカルではなく、**現代的でかわいらしい冬服**。厚手で長袖の**白いワンピース**（付け襟・リボンなし）の上に、アイボリーのウールのショートコート（Aライン、前を開けて羽織る）。白い厚手のタイツ、**よそゆきの赤いストラップシューズ**。首元にやわらかいマフラーを軽く巻く。クッキーの缶を抱えている
- 表情：顎を少し上げた、得意げですましたお姫さま顔
- 服（葬儀）：**黒いワンピース**に、**あの夜の赤い靴**
- 生者なので血色があり、光は暖かい。死者と並ぶと明確に違って見えるように

## 4. 立ち絵

### 仕様

- サイズ：**1024×1536（縦長）**、**背景透過PNG**
- 構図：**全身**、正面〜やや斜め、足元まで入れる。頭の上と足の下に少し余白
- 同じキャラの差分はすべて**同じポーズ・同じ構図・同じ縮尺**（顔だけ変える）
- 光：上方やや後ろからの光と、金色のリムライト
- 半透明・ぼかしなどの「幽霊表現」は画像に入れない（ゲーム側のシェーダーでかける）

### 表情差分

`facial_expression` の値をファイル名に使う。

## 8. 生成の進め方

キャラの見た目がぶれないように、この順で進める。

1. **スタイルボード**：研究室の背景を1枚と、カリルの立ち絵（`Default`）を1枚。画風を確定する
2. **キャラ設定画**：1人ずつ、正面・横・背面の三面図＋顔のアップ。以降はこれを基準にする
3. **全員の並び**：7人を同じ縮尺で横一列に並べ、背の差と色の差を確認する
4. **立ち絵（Default）**：1人ずつ、透過PNG
5. **表情差分**：各キャラの `Default` を元画像として編集し、**顔だけ**を変える。ポーズ・服・構図は変えない
6. **背景**：優先A → B → C
7. **スチル**：キャラ設定画を参照しながら、優先A → B
