## 方針

- **普通のノベル**。日をくり返すサイクルやパラメータ表示などのシステム要素は入れない
- 話の流れの中でこまめに選択肢を出す。**主人公の台詞はすべて選択制**（1択でもよい）。章で選択肢が1回しかないのはなし
- 面白さの軸は「**この人の望みは何か、なぜ死にきれないのか**」をプレイヤーが考察すること
  - 住人の過去は終盤まで直接は見せない。今の行動と言葉の食い違いだけを置く
  - カリルにも目的を説明させない
  - 研究室の冒頭で登場するのはカリルだけ。住人は話の流れの中で一人ずつ出す
- 地の文はジョナス（11歳）の一人称。誰かに語りかけるような、温度のある振り返りの声

### カリルの扱い：毎章の「おかえり」

ジョナスが出かけて戻るたびに、カリルは天井の星の下で待っていて「おかえり。どうだった？」と訊く。毎回同じやさしさで、毎回ほんの少しだけ、知っているはずのないことを知っている。名乗るまでは名前欄「？？？」。口調は柔らかく「僕」。

| 章 | 場面 | 拾える違和感 |
|---|---|---|
| 1 | 「おかえり」と望遠鏡。「テオは、君の友だちだからね」 | はぐらかす |
| 2 | フィルウとジョナスのところへ通りかかる。フィルウは急に丁寧語で「博士」。カリルはフィルウを見ず、ジョナスにだけ「新しいお友だちができたんだね」。フィルウの名前を呼ばない | フィルウの名前を呼ばない／フィルウの顔 |
| 2 | 何気ない助言。「ルネちゃん、テオとよく星を見てたよね。星の話をしてあげたら、喜ぶんじゃないかな」 | なぜ知っているのか／なぜテオの話をさせたがるのか |
| 3 | 「すき」まで届いたのに咲かなかったあと。「好きだけじゃ咲かないんだよ」 | 仕組みを最初から知っていて、言わなかった |
| 3 | レイフがルネを癒していると知っても「困ったね」と言うだけで止めない。リヴ「博士はレイフを止めないんだよ」 | 咲かせたいはずなのに止めない（ルネの願いがテオに向くまでは咲いてほしくない） |
| 3〜4 | 夜、星の下で二人きり。星の話をするときだけ別人の顔になる。「大事な名前はね、星につけるんだよ」。暗がりからフィルウが見ている | フィルウが惚れた顔／「父さんの星」／フィルウの嫉妬が第4章の「協力しろ」の動機に |
| 4 | 「ルネちゃんが咲いたら、だれを呼んでほしい？」。ジョナスの「テオも、一緒がいい」に、いちばんうれしそうに笑う | 同じ一言で、フィルウは怒鳴り、カリルは喜ぶ |

## プロローグ「流れ星の夜」

- **P-1 坂道**：2027年3月、フランス。坂の上まで走って振り返るジョナス。ルネとテオの紹介。缶を持たされる選択。テオの真鍮の望遠鏡と「父さんの星」。尾根の途中に、研究所の灯りがひとつだけ
- **P-2 展望台**：割れたクッキー（「運び賃」）。来ない父を待つテオ。最初の流れ星。ルネの願い「三人で、ずっと一緒にいられますように」。ジョナスは願わない。「こっちだよ」の声に、画面の指示どおり進む。床が崩れ、テオがジョナスの手首をつかんだまま、二人で落ちる
- **P-3 研究室・目覚め**：カリル（？？？）だけ。「君は、死んでしまった」「彼女が、とても悲しんでいるんだ」。テオのことを訊かれても笑うだけ。「大丈夫。方法はあるからね」。声に聞き覚えがある
- **P-4 最初の観測**：教会の棺はひとつ（テオの遺体はカリルが保存している）。ルネは何度も後ろを振り返る。「向こうの世界だよ」「僕たち、みんな死んじゃったから」「生きてる人たちに、声は届かない」。泣き出すルネ。「泣かせたくなんて、ないよね。いい方法を知ってるんだ。こっちへおいで」
- **P-5 硝子の扉**：冷たい手。「ここから、あの子のそばに行けるんだ」「君が決めていいんだ」。カリルは天井の、閉じ込められた星を見上げている

## 第1章「空いた机」

- ルネの部屋（夜）：缶にさわると音が鳴る（干渉できると知る）。「おやすみ、{player}。おやすみ、テオ」。その夜、ルネは眠れた
- 教室：空いた机が二つ、白い花が一輪ずつ。クラスメイトに問い詰められるルネを、小さな干渉で逃がす
- 秘密基地：入り口で立ち止まるルネ。回想（看板「三人以外、立ち入り禁止」と、テオが描いた約束の星）。「……うそつき」
- 夜：ルネの机にテオの望遠鏡。ジョナスは何もしていない。「……テオ」。僕じゃないだれかが、ルネのそばにいる
- 研究室：「おかえり」。「テオは、君の友だちだからね」。柱の陰に、片方の靴がない男の子。追いかけても、呼んでも、消える
- 引き：「またちびが増えてる」（フィルウ）

## 第2章：フィルウ

- 「お前、博士のなに。場合によってはぶっ飛ばすけど」→「ふーん」→「こっち来なよ。博士は何も言わないから。僕が教えてあげる」
- 「僕も死んだ」。撃たれた傷を見せびらかす。「しくじった。なんか、テキトーでいっかあと思ってさ」
- 「博士とあなたは、どういう関係なの」→「博士のことを口にするな」「僕の博士だから。僕以外が語るのは間違ってるよ」→「機嫌とってよ」（4択：「ごめんなさい」／「撃たれたとこ、もう一回見せて」／「博士のこと、教えて」→「君が知る必要ないよ」／何も言わない→「君、テオよりつまんないね」）
- カリルが通りかかる（「新しいお友だちができたんだね」）。カリルの助言（テオと星の話）
- 〔未定〕蘇りの異能が死者の生き返る方法であること、ここから干渉して咲かせることがわかる。フィルウが過去のいろいろな自分を咲かせようと当たり続けてきた気配（火事の夜、帳面の線）。暗く荒れた過去がある、とだけわかる

## 第3章：リヴとレイフ

- リヴとの取り引き：「きみはあの子に目をつけたの？　いいと思うよ。理にかなってる」「生き返る異能が咲いたとして、その人が、力をきみに使ってくれるとは限らないでしょ」「じゃあ、手伝ってあげるね」「もしきみが生き返れたら、あの子に頼んでくれないかな」。ジョナス「ふたりぶん、かな」→「……うん。よろしくね」
- ルネが元気になる。「かわいいね、彼女」「笑って過ごしてるだけじゃ、足りないんだよね」「やり方はいろいろあると思う」
- 夜、ルネの部屋で子守唄（ソルヴェイの歌）。「しーっ。やっと眠ったんだ」（レイフの影だけ）
- 「すき」だって。咲かない。「好きって、すごいじゃん。誰も今まで成功しなかった」。リヴは「その辺の人」で試してきた。カリル「好きだけじゃ咲かないんだよ」
- 「リヴは誰を見てるの？」「……手伝ってくれる？」（島の若い医者）
- レイフ登場：「きみ、リヴを手伝ってるって聞いた。たのし？　ねえちゃんとの冒険」「俺、弟のレイフ」「咲かせたくない。咲かせなければ、一緒にいられるもんね」
- カリルはレイフを止めない（「困ったね」）
- フィルウとレイフの掛け合い（「年下のくせに呼び捨てするなよ」「ガキが」「相変わらず口わっる！」）。二人は、別の世界線の医者を先回りして消して回っている
- レイフ「希望があるから、人って動けるんだよね。希望がなくなれば、それまで」。フィルウが茶化す（「死んでもがんばらないといけないの。もういいんじゃない。この根暗さ〜」「だったら執着してる僕に機会を寄越せよってことで、こうやって使ってるんだけどね。僕、賢いから」）。ジョナス「いじめはだめ」
- レイフとねえちゃん：「すっごく好き！　あたりまえだろ。でも、きみのとは違うけどね」「……ほんと、なんで俺より先に死んじゃったんだろうな」
- レイフの秘密：リヴは、このレイフが自分の世界の本当の弟ではないことを知らない。「ねえちゃんには内緒にして」「生き返れなくていい。生き返っても、ねえちゃんいないから……」
- 夜、星の下でカリルと二人（「大事な名前はね、星につけるんだよ」）。暗がりのフィルウ

## 第4章：博士とテオ

- フィルウ「君たちは僕に協力するんだぞ」。生き返らせたいのは「博士と、僕。それ以外ないよ」。「死んだらもうダメなんだろうね。だから、君があの女の子のこと、がんばってよ」
- 「リヴと約束した」→「リヴは知らないよ。レイフと……あともう一人と、ここで仲良くしてればいい」。「女の子みんなキライ」
- 「テオも、一緒がいい」→「その名前、僕の前でもう二度と口に出さないで。いい？　わかった！？」
- カリル「ルネちゃんが咲いたら、だれを呼んでほしい？」→「テオも」→ いちばんうれしそうに笑う
- 〔未定〕フィルウの過去から、カリル・テオ・フィルウの関係に迫る。火事（テオの未練だけを燃やそうとした）。その中で、カリルの目的（あの夜のすり替え）を知る

## 設定の改訂点（設定資料より優先）

**ルール**
- 異能は、その人のいちばん強い願いの形で咲く。咲いても蘇りの力になるとは限らない。蘇りになるのは「戻ってきてほしい」という願いのとき
- 力を誰に使うかは、咲いた人が選ぶ。一人とは限らない
- 死者がルネの想いを自分に向けさせようとするのは、ルネに選んでもらうため
- 死者の想いでは咲かない（フィルウはこれを知っている）

**フィルウ**
- 死因：裏の世界で撃たれた（「しくじった。テキトーでいっかあ」）。博士を失ったあと、生きる気をなくしていた
- 火事の動機は「テオ（博士の未練）だけを燃やそうとした」。博士はテオの遺体を取りに炎へ戻って死んだ
- 研究室では、過去のいろいろな自分を咲かせようと当たり続けている（火事の夜に何度も戻る。帳面の線は試行の数）
- 生き返らせたいのは「博士と、僕」。テオの名前を口にされることを許さない。「女の子みんなキライ」
- ジョナスには「ちび」と呼び、軽く脅すように話す。博士の前でだけ丁寧語（案）

**リヴ・スン（15）／レイフ・スン（16）**
- ノルウェーのフィヨルドの島で育った双子。毎日、渡し船で海峡を渡って学校へ通っていた。深層東京との関係はなし
- リヴの世界：冬、レイフが海峡で死ぬ（15歳）。リヴも、同じ冬に同じ海で死ぬ
- レイフの世界：リヴが海峡で死ぬ（15歳）。レイフは16歳になるまで岸で待ち続け、同じ海で死ぬ
- 生まれた順ではリヴが姉。レイフは「ねえちゃん」と呼ぶ（一人称「俺」）
- 研究室のレイフは、リヴの本当の弟ではない。レイフは知っていて隠している。リヴは知らない
- リヴの目当ては、島の若い医者（レイフの蘇生を最後まで続けて、間に合わなかった人）
- レイフはフィルウと組んで、医者を別の世界線で先回りして消して回る。リヴが自分を使い果たすのを止めるため
