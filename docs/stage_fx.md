# 演出エンジン（背景シェーダー・画面効果・演出トラック）

`index.html` の本体シェーダーの前後にパスを足して、画面をリッチにする仕組み。

| ファイル | 内容 |
|---|---|
| `js/stage-shaders.js` | 背景シェーダー（場面ごと）、ブルーム、仕上げシェーダー |
| `js/stage.js` | 実行部分（HHStage）。場面ごとの見た目（`LOOKS`）、`fx` コマンド、デバッグ「演出」タブ |
| `js/stage-cues.js` | 演出トラック。原稿の行を指して `fx` を差し込む |

3つとも読めなかったり WebGL で失敗したりしたときは、本体は元どおりの描き方で動く。

## 描く順番

1. **背景パス**：背景を FBO に描く
   - 画像のない背景は手続きで描く（タイトルは `lab` の変形、`black` は真っ黒）
   - 画像のある背景（`BG_IMG`）は、ゆっくり寄るカメラと空の瞬きを足す。**画像を足せば、そちらが優先される**
2. **本体**：`index.html` の FS がそのまま描く。背景は 1 の FBO を読む。立ち絵には場面の色の縁の光（リムライト）と環境光が乗る。スチルもゆっくり寄る
3. **仕上げ**：ブルーム → ゆがみ・粒子・色調・特殊演出

## 場面の見た目（LOOKS）

背景キーごとに、色調・ブルーム・粒子・縁の光の色などを `js/stage.js` の `LOOKS` に書く。
背景か `@phase` が変わると、`fx` で上書きした値はその場面の既定値に戻る。

## fx コマンド

GameCommand で受ける。原稿に直接書くなら `@cmd fx snow 1 2`、演出トラックなら `'snow 1 2'`。
使える命令の一覧は `js/stage-cues.js` の先頭にある。デバッグ（Tab）の「演出」タブで、ためし撃ちと任意の `fx` の実行ができる。

## 演出トラック

```js
['第1章|空いた机', 'かたん。', 'touch 1370 650'],
```

- 場面（`@phase` の「大|小」、二度目は `#2`）＋行の書き出し（「名前：」は含めない）で場所を指す
- 指した行と同時に（Join で）`fx` が走る。行の書き出しが空なら場面の頭、`@bg キー` ならその場面の中の背景の切り替え
- 原稿の行が書き換わって見つからなくなったものは、デバッグ「演出 › 置けなかった演出」に出る（コンソールにも出る）
- 原稿（`PROLOGUE`）には手を入れないので、原稿の編集とぶつからない
